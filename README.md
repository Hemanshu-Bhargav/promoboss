# promoboss
Side Project. Inspired from school assignment, a web service which centralizes storage of promotional codes and their progress throughout the promotional code lifecycle.

A web-based data management tool which centralizes addition and deletion of promotional codes.

- Original login system was scrapped on discovery of tutorial by Brad Traversy <https://github.com/bradtraversy>. As a result, new login system was adapted from <https://github.com/bradtraversy/node_passport_login/>.
